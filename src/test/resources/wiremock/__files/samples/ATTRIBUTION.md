# Audio samples

Speech samples come from LibriVox **Short Poetry Collection 195** (2019),
https://archive.org/details/spc195_1909_librivox. LibriVox recordings are in the
public domain ([Public Domain Mark 1.0](http://creativecommons.org/publicdomain/mark/1.0/)).

Each sample is a different poem read by a different volunteer (the file suffix is the
reader's code), so the samples are easy to tell apart. Durations (33 s – 96 s) are in the
range of typical voice messages.

`mp3/` holds the original LibriVox files; `wav/` (16 kHz mono), `amr-nb/` and `amr-wb/` are transcoded from them.
